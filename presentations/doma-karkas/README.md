# Презентация компании «Дома-Каркас» (Интел Групп)

PDF-презентация о компании и проекте для [doma-karkas.ru](https://doma-karkas.ru/) —
строительство загородных домов под ключ в Москве и Московской области.

## Файлы

| Файл | Описание |
|------|----------|
| **`doma-karkas-presentation.pdf`** | Готовая презентация — 12 слайдов, формат 16:9 (960×540 pt) |
| `index.html` | Исходник презентации. Полностью автономный: шрифты (Prata + Montserrat) встроены как base64, иконки — inline SVG, никаких внешних зависимостей |
| `render.js` | Рендер `index.html` → PDF + PNG-скриншоты (Playwright / Chromium) |
| `build-fonts.py` | Генерация встроенного `@font-face` CSS из статических woff2 (Fontsource) |

## Структура (12 слайдов)

1. Обложка — позиционирование и ключевые цифры
2. О компании — миссия и принципы
3. Ключевые цифры — 700+ домов, 15 лет, до 20 лет гарантии, рейтинг 4.9
4. Технологии строительства — каркас, газобетон, кирпич, брус и др.
5. Готовые проекты — каталог, ценовые уровни (2,9–22,8 млн ₽)
6. Как мы работаем — 6 этапов от участка до ключей
7. Контроль качества — три уровня контроля
8. Почему выбирают нас — 6 преимуществ
9. Гарантии и финансирование — гарантия, ипотека, эскроу
10. Команда — ключевые специалисты
11. Репутация — рейтинги и сертификаты
12. Контакты — телефоны, почта, CTA

## Как пересобрать PDF

`index.html` самодостаточен — его можно открыть в браузере и распечатать в PDF
(landscape, поля 0). Для автоматического рендера:

```bash
# требуется Node.js + playwright-core; путь к Chromium задан в render.js
node render.js index.html doma-karkas-presentation.pdf ./shots
```

`render.js` также сохраняет PNG-скриншот каждого слайда в указанную папку.

## Замечания по данным

Контент собран из публичной информации на doma-karkas.ru (о компании, технологии,
этапы, команда, гарантии, контакты). Цифра «до 20 лет» отражает заявленную на сайте
гарантию; средний ценовой диапазон приведён по крайним значениям каталога.

## Дизайн

- **Палитра:** глубокий лесной зелёный + латунный акцент + тёплый кремовый фон
- **Шрифты:** Prata (заголовки, засечки) + Montserrat (текст, цифры) — полная кириллица
- Светлые и тёмные слайды чередуются для ритма; единый нижний колонтитул с нумерацией
