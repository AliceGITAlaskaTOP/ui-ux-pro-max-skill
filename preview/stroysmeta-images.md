# СтройСмета — слоты изображений

Страница `preview/stroysmeta.html` работает **без единой внешней картинки**: все визуалы
нарисованы инлайновым SVG в чертёжной стилистике (фасад, терраса, план участка, разрез
стены, каркас стройки). Это осознанное решение, а не заглушка — разрез стены с подписями
слоёв объясняет «узел» лучше, чем фотография.

Поверх каждого чертежа лежит `<img class="viz-photo" data-photo>`. Он прозрачен и
проявляется только после успешной загрузки файла (`load`, без `onerror`). Поэтому чертёж
никогда не «моргает», а фото подхватывается автоматически, как только окажется доступным.

## Как подставить свои фотографии

Замените `src` у нужного `data-photo` — остальное произойдёт само.

| Слот | Где на странице | Пропорция | Что снимать |
|---|---|---|---|
| `hero` | мокап сметы в первом экране | 16:9 | общий вид дома, объект смещён вправо |
| `facade` | галерея, ракурс 01 | 16:10 | главный фасад, рассеянный дневной свет |
| `terrace` | галерея, ракурс 02 | 16:10 | терраса, тёплый свет изнутри, синий час |
| `drone` | галерея, ракурс 03 | 16:10 | вид с дрона: дом, участок, подъезд |
| `winter` | галерея, ракурс 04 | 16:10 | тот же дом зимой |
| `phone` | экран телефона в секции 05 | 16:11 | дом целиком по центру кадра |
| `cta` | фон финальной секции | 21:9 | стройка, пустое место в верхней половине |
| `node` | карточка «Узлы» (сейчас разрез) | 3:4 | деталь узла крупным планом |

Единый style suffix для набора:

```
architectural photography, overcast diffused daylight, muted grey-green palette,
35mm lens, natural colors, fine film grain, no text, no logos
```

Логотипы, сертификаты, фото команды и реальные объекты компании — только настоящие,
генерация здесь неуместна.
